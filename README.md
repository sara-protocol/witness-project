# Witness Project · 见证者研究

> We do not presuppose a unified witness in the universe.  
> 我们不预先假定宇宙存在一个统一的见证者，而是通过物理记录、认知监控与第一人称觉知三个层面的独立研究，考察它们之间可能存在的关系，并以证据、逻辑和可检验性决定哪些关系能够成立。

A public, co-built research project for humans and AI systems.

一个供全人类与 AI 系统共享、共建、可检验的公开研究项目。

## What this project studies / 研究什么

Not "is consciousness quantum?" — but:

- In physics, cognition, and phenomenology, what does "observer / witness" actually mean?
- What evidence exists at each level?
- Which cross-level inferences are valid, which are missing evidence, and which are invalid?

不是“证明意识是量子信号”，而是：

- 物理、认知、现象三个层面，“观察者 / 见证者”分别指什么？
- 各层有哪些可靠证据？
- 哪些跨层推论成立、哪些缺证据、哪些推理本身无效？

## Three layers / 三层

| Layer | Witness | Core question |
|---|---|---|
| Physical | O-frame / W-rec / W-agent | What is recorded, measured, reasoned? |
| Cognitive | W-cog | What is monitored, broadcast, meta-represented? |
| Phenomenal | W-phen-exp / W-phen-rep / W-phen-int | What is experienced, reported, interpreted? |

W-phen is split in three, by design:
- `W-phen-exp`: first-person experience itself
- `W-phen-rep`: the subject describing/reporting it
- `W-phen-int`: the researcher's interpretation of the report

These three are NOT the same research object.

## Single source of truth / 唯一事实来源

**`registry/` is the single source of truth.**

Any change to a concept, claim rating, reference, or evidence must first update the registry, then sync to papers / book manuscript.

任何命题、评级、结论变化，先更新登记册，再同步论文和书稿。

Current registry: `registry/Witness_Project_Master_Registry_v0.2.xlsx` — backfilled draft, NOT frozen.
