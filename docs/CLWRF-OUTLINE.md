# CLWRF — Cross-Level Witness Relations Framework (candidate)

Status: candidate analytical framework, NOT a verified theory.

## Purpose
Not to prove a unified witness, but to analyse relations between levels consistently.

## Components
1. Level identification (O-frame / W-rec / W-agent / W-cog / W-phen-exp/rep/int)
2. Concept type identification
3. Relation type identification (physical realisation / information transfer / functional dependence / neural realisation / first-person relation / ontological identity)
4. Evidence type matching
5. Bridging proposition registry (BR-)
6. Inference validity check
7. Falsification condition + applicability boundary

## Test for originality (required before claiming contribution)
Apply CLWRF independently to cases from different fields, compare with existing frameworks:
- Does it reduce conceptual confusion?
- Does it identify invalid inferences that others miss?
- Does it generate new, testable predictions?
If not, revise or abandon it.

## Falsifiability
Each BR- must have: definition, premises, supporting evidence, counter-evidence, testable prediction, falsification condition.
