# Unified Method Protocol & Evidence Evaluation Manual v1.0 — Outline (draft for Sprint 1)

## 1. Research type
Scoping review (PRISMA-ScR) + proposition-level critical evaluation (project-added step, declared as deviation).

## 2. Retrieval by RQ
- RQ1 terminology: systematic term retrieval
- RQ2 physics: theory-anchored retrieval + citation tracking (decoherence, quantum Darwinism, Wigner's Friend, Local Friendliness)
- RQ3 cognition: theory-anchored (GNWT, IIT, HOT, RPT, AST, predictive processing)
- RQ4 phenomenology / testimony: systematic retrieval + primary texts
- RQ5 bridging: explicit cross-level propositions only

Each field: databases, date, Boolean string, language, time range, inclusion/exclusion, screening log.

## 3. E-M-T-L-I scales (TO BE FROZEN IN v1.0)
- E: empirical support
- M: math / theory status
- T: testability
- L: logic / inference validity
- I: interpretation / philosophical stance

Each field: levels, applicability conditions, examples, N/A, insufficient-info, contested markers.
Rules: no total score; no converting old A-E / I1-I3 directly; no using majority/minority as I criterion.

## 4. Screening
Two independent human reviewers, pre-registered disagreement rule, screening log, Cohen's kappa.
AI first-pass only with recall validation on 10-20% random sample.

## 5. Writing rules R1-R7
R1 level subscript, R2 strength wording, R3 bridging single-listed, R4 metaphor labelled, R5 counter-evidence mandatory, R6 trivial claims as background facts, R7 source hierarchy (original > secondary).

## 6. Bilingual consistency
Chinese claim — English claim — claim ID — grade — qualifier — reference. No strength drift.
